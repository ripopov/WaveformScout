# Pyrox - PYthon trace Reader OXidized

PyO3 Python bindings for trace and waveform readers.

Python bindings for the wellen waveform library.
Based on https://github.com/ekiwi/wellen/tree/main/pywellen

## About

pyrox provides Python bindings for the Rust-based wellen library, enabling fast loading and processing of VCD, FST, and
GHW waveform files.

## Building

This package is built using maturin:

```bash
maturin develop --release
```
